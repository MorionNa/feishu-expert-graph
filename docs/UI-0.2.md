# 专家关系图谱 · UI 0.2

## 设计目标

以关系网络为主画面。轻量顶部栏、探索/路径切换、按需出现的人物档案，减少长驻统计卡片与调试信息。沿用飞书蓝色与现有 Vite + 原生 JS + Cytoscape，不增加依赖，不迁移框架。

参考 edisonmbli/refactoring-ui-skill 的视觉层级、间距、权重与对比度、分级阴影、空状态和视觉验证经验。设计由本项目功能出发，不复制参考仓库的模板或书籍图文。

参考来源：https://github.com/edisonmbli/refactoring-ui-skill

## 交互

- 探索网络：姓名/人员ID/领域/当前身份搜索；点击人员列表或图节点打开详情、突出相邻关系。
- 人员详情：身份、履历、直接连接列表；可以设为路径起点/终点。
- 寻找路径：交换起终点、逐段高亮、分步骤列出关系；尊重原有方向；B→A 的箭头也按实际方向绘制。
- 节点拖动与缩放：有数据变更时增量更新元素，不销毁 Cytoscape，不主动重新布局；无变化时保持图实例、位置、缩放。
- 数据异常：保持可见，不伪装成功；错误显示在顶部，无法匹配记录在底部提供诊断入口。
- 键盘：/ 聚焦搜索，Enter 选择首个结果，Escape 关闭浮层/退出聚焦；Tab/方向键可操作工具。
- 窄屏：上方工具、下方画布、按需弹出的详情；尊重 reduced-motion。

## 保留边界

`src/feishu.js`、`src/graph-data.js`、依赖版本和 Pages 部署流程均不修改。沿用用户已经验证成功的 Config/View 读取路径、v2 customConfig、Base标识和表/字段映射。不重建飞书表、不自动重新保存配置、不上传专家数据。

真实页面出错时不会自动换成演示。公开演示必须显式使用 `?demo=1` 或 `?demo=showcase`；后者为9位虚构人员，用于观察较丰富网络效果。

原版本备份分支：`backup/pre-ui-polish-20261018`。界面更新后重新打开飞书页面即可加载新版；已保存的 v2 配置可直接复用。浏览模式中数据设置只读，永久修改应进入飞书组件配置模式。

## 本地验证记录（2026-10-18）

新增8项 Node 单元测试通过。Chromium + Playwright 使用从既有构建产物取得的真实 Cytoscape 运行时和合成人物数据验证：搜索、键盘、人物详情、3跳路径、不可达反向路径、零跳路径、缩放、更新后保留实例/位置/缩放、删除关系、删除当前人物、配置弹窗、空搜索结果。375/760/1024/1280/1920px 宽度无水平溢出，详情关闭按钮可操作。另对50/300/1000节点合成数据做了初次渲染检查。

Create/Config/View 三种宿主生命周期通过模拟 SDK 检查：自动读取、恢复 Base/字段映射、保存 v2 配置、展示态数据变化事件。**这是模拟测试，不是已登录的真实飞书租户端到端测试。** 真实读取协议文件保持不变，但新版在用户实际飞书宿主内仍需确认。

本地浏览器测试为了适应无外网环境使用模块注入；正式构建与原有单元测试仍由 GitHub Actions 执行。本报告不把浏览器场景检查等同于完整安全审计或 WCAG 认证。
